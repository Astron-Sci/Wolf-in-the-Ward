# 群里有个狼病友 · Wolf in the Ward

**An Intern's Seven Days in a Patient Chat Group**

你是一名刚进患者微信群的实习医生。七天里，群里不断有人散布与解剖学相关的健康谣言——
你要从聊天流里找出那些可疑说法，用解剖学知识辟谣，并揪出反复造谣的那个人。

---

## 怎么玩

1. **进群**：开局随机进入 8 个患者群中的一个；
2. **找谣言**：每天群里有 1~2 条可疑说法，点中其中的关键词进入辟谣；
3. **辟谣**：新手档直接选一条正确的解释；进阶/硬核档先选辟谣方向，再选具体理由；
4. **看后果**：选的理由无论对错都会发进群里，说错了会被病友质疑；
5. **攒威信**：威信越高，群主越信你；威信跌破 10 会被群主踢出群；
6. **揪狼**：辟谣成功后可举报发帖人——但**举报跟风转发的普通人会冤枉好人**；
7. **第 7 天**：按威信授予头衔（庸医 → 华佗再世），同时结算群内剩余狼数。

### 怎么分辨「狼」和「跟风的人」

- **狼**：反复发布**原创**错误说法（「我邻居做了就瘫」「千万别做手术」）；
- **跟风者**：只是转述（「刚看到有人说…我也听好几个人这么讲过，转给大家看看」）；
- 点任意群友的**头像**，可以查看他本局的完整发言记录。

## 三种难度

| 档 | 选项 | 提示 | 查课本 | 限时 |
|---|---|---|---|---|
| 新手 | 单层（3 选 1）| 有 | 可 | 无 |
| 进阶 | 两级（方向→理由）| 有 | 可 | 无 |
| 硬核 | 两级 | 无 | 不可 | 每题 40 秒，选项打乱 |

## 怎么运行

- **电脑**：双击 `index.html` 即可；
- **手机同 WiFi 试玩**：在目录下执行 `python -m http.server 8765`，手机访问 `http://<电脑IP>:8765`；
- 零依赖、免安装、单文件，全部素材（含 25 张头像）已内嵌。
